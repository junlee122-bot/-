# Betman Value Analyzer

한국 **베트맨(프로토 승부식) 전용** 스포츠 베팅 가치 분석 시스템.

실제 베팅은 **베트맨에만** 한다는 전제로 설계되었습니다. 해외 사이트 배당은
**참고용(컨센서스 확률 추정)** 으로만 사용하며, 해외 베팅을 실행하는 기능은
넣지 않습니다.

> ⚠️ **시스템에 명시된 전제**: 베트맨 환급률은 약 **63%** 입니다.
> 즉 발매되는 모든 항목의 장기 기대값은 **구조적으로 마이너스**이며,
> 아무리 정보량이 많아도 이 환급률의 벽을 넘어 "장기적으로 이익이 나는 베팅"을
> 만들 수는 없습니다. 이 시스템의 목적은 "이기는 베팅"을 찾는 것이 아니라,
> **여러 마이너스 항목 중 상대적으로 덜 불리한(해외 컨센서스 대비 가치 있는) 항목을
> 골라내고, 각 항목이 정확히 얼마나 마이너스인지 투명하게 보여주는 것**입니다.

---

## 목적

1. 베트맨 고정배당이 해외 시장 컨센서스 대비 **상대적으로 가치 있는** 항목 탐지.
2. 베트맨 환급률(63%)을 반영해 각 베팅의 **기대값(EV, 마이너스 포함)** 을 정확히 표시.
3. 정형/비정형 데이터를 종목 공통 포맷으로 정규화하여 분석.
4. 예산 한도 안에서만 베팅 기록을 관리하고 초과 시 경고.

---

## 4-레이어 아키텍처

각 데이터 소스는 인터페이스로 분리되어 있어 **나중에 mock → 유료 API로 교체** 가능합니다.

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 수집 (collection)                                          │
│    - 정형:  경기/통계/라인업/부상  ← MatchCollector            │
│            해외 북메이커 배당       ← OddsCollector            │
│            베트맨 발매·고정배당     ← BetmanCollector          │
│    - 비정형: 뉴스/분석글 (정식 API/피드만) ← NewsCollector     │
│    → 종목 공통 포맷(NormalizedMatchBundle)으로 정규화          │
├─────────────────────────────────────────────────────────────┤
│ 2. 저장 (storage)                                             │
│    - 과거 회차·경기 통계 누적, 팀별 홈/원정 분리 전적 축적     │
│    - 프로토타입: SQLite                                        │
├─────────────────────────────────────────────────────────────┤
│ 3. 분석 (analysis)                                            │
│    - 해외 배당 → 내재확률(1/배당) → de-vig(마진 제거)          │
│    - 환급률 63% 반영 EV 계산                                   │
│    - 해외 컨센서스 vs 베트맨 배당 갭 → value 점수              │
│    - 종목별 무승부 구조/데이터 신뢰도로 보정                   │
│    - 비정형 → LLM 요약·감성분류 → 긍정/부정 신호 플래그 →      │
│      value 점수에 보조 가중치                                  │
├─────────────────────────────────────────────────────────────┤
│ 4. 출력 (output)  ─ 웹 대시보드                               │
│    - 축구/야구/농구 기본 섹션, value 점수 순 정렬             │
│    - 그 외 종목은 캘리브레이션 기준선 넘는 픽만 '주목 픽'      │
│    - 각 픽: 베트맨 배당 / 내재확률 / EV(−) / value / 근거 신호 │
│    - 예산 한도 기반 베팅 기록 관리 + 초과 경고                 │
└─────────────────────────────────────────────────────────────┘
```

## 예산 구성안 (참고)

이 프로토타입은 **무료 / mock 데이터**로 전체 구조를 먼저 검증하도록 만들어졌습니다.
유료 API로 교체할 때 예산대별 현실적 조합은 다음과 같습니다.

| 월 예산 | 해외 배당 | 정형 통계 | 비정형(뉴스) | 비고 |
|--------|-----------|-----------|--------------|------|
| **~$0 (현재)** | mock | mock | mock | 구조 검증·로직 개발 |
| ~$50 | The Odds API 저가 티어 | 무료/저가 스탯 | 무료 뉴스 RSS/피드 | 종목·갱신빈도 제한 |
| ~$200 | The Odds API 유료 티어 | 통계 API 기본 | 뉴스 API | 축구/야구/농구 핵심 커버 |
| ~$500 | OddsJam급 | Sportradar/Opta 기본 | 뉴스 API 풀 | 다종목·고빈도·풍부한 비정형 |

> 모든 외부 수집은 **정식 API/허용된 피드만** 사용합니다. 무단 스크래핑은 쓰지 않습니다.

### 예측 변수(feature) 스키마

세 종목(축구/야구/농구, 해외 포함)의 예측 변수는 `domain/features.py` 에서
`Feature[T]` 래퍼로 정규화한다. 핵심 원칙:

- **결측 명시**: 값을 모르면 0으로 뭉개지 않고 `Feature.missing`(`present=False`).
- **항목별 가중치 분리**: feature마다 이름을 가져, `analysis/weights.py` 에서
  가중치를 따로 부여 → value 점수 모델을 **종목별로 분리·캘리브레이션**.
- **종목별 핵심 변수에 최고 가중치**: 축구=xG·확정라인업, 야구=선발투수,
  농구=휴식(백투백)·스타결장.
- **비정형은 보조 가중치로만**: 부상 뉴스/분석글은 LLM이 해당 플래그(예:
  "주전 공격수 결장", "백투백")로 환산해 보조 반영(3단계).
- **사후 검증 로깅**: `analysis/provenance.py` 가 픽별로 사용한 입력값(+가중치,
  결측 여부)과 경기 결과를 JSONL로 남겨 백테스트/재캘리브레이션에 사용.

| 구분 | 공통(3종목) | 축구 | 야구 | 농구 |
|------|------------|------|------|------|
| 핵심 | 최근폼/H2H/일정/라인무브먼트/부상 | **xG·xGA, 확정라인업** | **선발투수(ERA/FIP/WHIP)** | **휴식·백투백, 스타결장** |
| 보조 | 동기(순위·잔여일정)·더비 | 세트피스·슈팅·심판·날씨·무승부경향·리그정규화 | 불펜피로·좌우스플릿·파크팩터·바람 | 페이스·공수효율·매치업·홈코트 |

## 현재 구현 상태 (단계적 진행)

- [x] **0단계** — 폴더 구조 + 4개 레이어 모듈 인터페이스 설계
- [x] **1단계** — 데이터 수집 레이어 (인터페이스 + mock 구현 + 정규화 파이프라인)
- [x] **1.5단계** — 종목별 예측 변수 수집·정규화 (Feature 스키마 + 가중치
  레지스트리 + 픽별 입력/결과 로깅)
- [ ] **2단계** — 저장 레이어 (SQLite, 과거 전적 누적)
- [ ] **3단계** — 분석 레이어 (de-vig / EV / value 점수 / LLM 신호)
- [ ] **4단계** — 출력 레이어 (웹 대시보드 + 예산 관리)

## 실행 (수집 데모)

```bash
pip install -r requirements.txt        # 1단계는 표준 라이브러리만으로도 동작
python -m scripts.run_collection
```

mock 수집기가 축구·야구·농구·배구 경기를 생성하고, 해외 배당/베트맨 배당/뉴스를
종목 공통 포맷으로 정규화한 뒤 요약을 출력합니다.
